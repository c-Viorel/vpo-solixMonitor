Find your camera IPs — in the TAPO app

Even without router access, the TAPO app shows the camera's local IP:

  1. Open the TAPO app → tap the camera
  2. Tap the ⚙️ gear icon (top right)
  3. Scroll to Device Info
  4. Note the IP Address shown there

ℹ️ The RTSP stream only works while your NAS and cameras are on the same local network (or connected via VPN).

2

Cameras on a different network? Use Tailscale (free, no port forwarding)

Install Tailscale on any device on the cameras' network (PC, laptop, phone). It creates a private VPN tunnel — your NAS can then reach the cameras as if they were local.

On the remote device (same network as cameras):

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

On your NAS:

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

Then use the camera's Tailscale IP (100.x.x.x) as the camera IP below.

3

Configure & enable cameras

Add to /volume2/docker/solix-monitor/.env on your NAS: 

CAMERAS_ENABLED=true

# TAPO RTSP format: rtsp://<email>:<tapo-password>@<camera-ip>:554/stream1
CAMERA1_RTSP_URL=rtsp://your@email.com:password@192.168.50.XXX:554/stream1
CAMERA1_NAME=Living Room

CAMERA2_RTSP_URL=rtsp://your@email.com:password@192.168.50.YYY:554/stream1
CAMERA2_NAME=Front Door

# Password to protect the HLS stream (anything you like)
HLS_READ_PASS=changeme

Then start the MediaMTX container and restart the app: 

cd /volume2/docker/solix-monitor
sudo docker compose --profile cameras up -d
sudo docker compose restart solix-monitor

Why not TAPO cloud API? The TAPO app streams video via a proprietary DTLS/WebRTC relay — TP-Link doesn't expose this to third parties. There is no official cloud API for live video. The RTSP approach above is the standard way to access TAPO cameras programmatically.
